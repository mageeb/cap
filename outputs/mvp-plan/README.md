# Week 7 planning workbook

`mvp-implementation-plan.xlsx` is the proposed work-item hierarchy generated from Weeks 5–6 for the Week 7 exercise. Open it in a spreadsheet application; the PNG files preview the hierarchy and scope sheets.

The workbook is a planning aid, not an approved final backlog or evidence that its tasks are complete. Review source claims, unresolved choices, dependencies and completion checks before execution. The classroom backend implements only part of this plan.

`build.mjs` is the original instructor-side generation source. It uses the instructor's local bundled Artifact Tool runtime and absolute paths; it is retained for provenance, not presented as a portable student build command. Students do not need that runtime to open or review the workbook.
